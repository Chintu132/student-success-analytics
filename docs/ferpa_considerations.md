# FERPA Considerations

This project uses public/sample data for learning purposes.

If this project were used in a real university environment, student privacy
would be very important. Personal information should be protected, access
should be limited, and reporting should be shared only in the right level
of detail.

Key considerations:
- avoid exposing personal student information
- use anonymized or sample data
- share aggregated results where possible
- apply role-based access for sensitive reporting
