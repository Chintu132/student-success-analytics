# Data Dictionary

## dim_student
| Column | Type | Description |
|--------|------|-------------|
| id_student | INTEGER | Unique student identifier (anonymized) |
| gender | TEXT | Student gender (M/F) |
| region | TEXT | Geographic region |
| highest_education | TEXT | Highest prior education level |
| imd_band | TEXT | Index of Multiple Deprivation band (socioeconomic indicator) |
| age_band | TEXT | Age range: 0-35, 35-55, 55<= |
| num_of_prev_attempts | INTEGER | Number of previous attempts at the module |
| studied_credits | INTEGER | Total credits the student is studying |
| disability | TEXT | Whether student has declared a disability (Yes/No) |
| enrollment_type | TEXT | First-Time or Returning student |

## fact_enrollment
| Column | Type | Description |
|--------|------|-------------|
| id_student | INTEGER | FK to dim_student |
| code_module | TEXT | Course module code (e.g., AAA, BBB) |
| code_presentation | TEXT | Term/presentation code (e.g., 2013J, 2014B) |
| date_registration | INTEGER | Days relative to course start when student registered |
| final_result | TEXT | Outcome: Pass, Distinction, Fail, Withdrawn |
| final_grade | TEXT | Letter grade equivalent: A, C, F, W |
| grade_points | REAL | Numeric grade: 4.0, 3.0, 1.0, 0.0 |
| passed | INTEGER | 1 if Pass or Distinction, 0 otherwise |
| withdrew | INTEGER | 1 if Withdrawn, 0 otherwise |
| studied_credits | INTEGER | Credits for this enrollment |

## fact_weekly_engagement
| Column | Type | Description |
|--------|------|-------------|
| id_student | INTEGER | FK to dim_student |
| code_module | TEXT | Course module code |
| code_presentation | TEXT | Term/presentation code |
| activity_week | INTEGER | Week number (1, 2, 3...) relative to course start |
| total_clicks | INTEGER | Total VLE/LMS interactions that week |
| sites_visited | INTEGER | Number of distinct VLE sites accessed |
| days_active | INTEGER | Number of distinct days with activity |

## fact_retention
| Column | Type | Description |
|--------|------|-------------|
| id_student | INTEGER | PK, FK to dim_student |
| cohort_term | TEXT | First term the student enrolled (defines cohort) |
| terms_enrolled | INTEGER | Total terms the student has been enrolled |
| cumulative_gpa | REAL | Average grade points across all enrollments |
| cumulative_credits | INTEGER | Total credits attempted |
| is_graduated | INTEGER | 1 if latest result is Distinction |
| is_dropped_out | INTEGER | 1 if latest result is Withdrawn |
| retention_status | TEXT | Retained, Graduated, At-Risk, Dropped Out |

## engagement_scores (generated by analysis)
| Column | Type | Description |
|--------|------|-------------|
| id_student | INTEGER | FK to dim_student |
| code_module | TEXT | Course module code |
| code_presentation | TEXT | Term code |
| engagement_score | REAL | Composite score 0-100 |
| risk_flag | TEXT | AT-RISK (<40), WATCH (40-60), ON-TRACK (60+) |
